# Хаоши · 好时 — кофейня 24 сезонов

MVP Telegram-бота и мини-приложения для кофейни, которая живёт по китайскому календарю: каждые 15 дней выходит новый сезонный напиток.

Маскот — панда-бариста **Хао-Хао** 🐼

## Что умеет прототип

**Мини-приложение** (`webapp/`):
- **Главная:** текущий сезон из 24, обратный отсчёт до смены напитка, история сезона, фраза дня на китайском с озвучкой, предсказание-палочка (раз в день).
- **Меню:** сезонный напиток, хиты Китая, классика, китайские десерты; корзина.
- **Предзаказ:** выбор времени, скидка 10% за фразу на китайском, «оплата» через СБП (демо, деньги не списываются).
- **Китайское имя:** транскрипция имени и имя со смыслом, превью стакана с именем.
- **Паспорт сезонов:** 24 печати, слепая коробка (каждый 10-й заказ), коллекция фигурок.

**Бот** (`bot/bot.py`, aiogram 3):
- `/start` — приветствие и кнопка мини-приложения;
- `/season`, `/phrase`, `/fortune`, `/name Алина`;
- принимает заказ из мини-приложения и подтверждает его; может дублировать заказ в чат бариста.

Данные (сезоны, меню, фразы, имена) лежат в одном файле `webapp/data.js` и общие для бота и мини-приложения.

## Как запустить

### 1. Мини-приложение на GitHub Pages
1. Залейте репозиторий на GitHub.
2. **Settings → Pages → Source: GitHub Actions.**
3. После пуша в `main` приложение будет доступно по адресу `https://<логин>.github.io/haoshi-bot/`.

Посмотреть локально:
```bash
python -m http.server 8765 --directory webapp
```

### 2. Бот
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `WEBAPP_URL`.
3. Установите зависимости и запустите:
```bash
pip install -r bot/requirements.txt
python bot/bot.py
```
4. Напишите боту `/start` и нажмите «🍵 Открыть меню Хаоши».

> Заказ возвращается в бот только при открытии через кнопку клавиатуры — так устроен `Telegram.WebApp.sendData`.
